# CICAN ART OF BUSINESS

**SEE BUSINESS DIFFERENTLY.**

An independent creative business consultancy founded by **CICAN GEORGE ALIN**.

This repository contains the GitHub Pages website for CICAN ART OF BUSINESS: a creative consultancy exploring how real business environments, original photography and artistic line-art transformations can become bespoke corporate publications and visual brand experiences.

## Website

- Production URL: https://cicangeorgealin.github.io/cican-art-of-business/
- Repository: https://github.com/CicanGeorgeAlin/cican-art-of-business
- Hosting: GitHub Pages
- Branch: `main`

## Version 1 structure

- `index.html` — semantic single-page website
- `assets/css/style.css` — responsive visual identity and layout
- `assets/js/main.js` — mobile navigation and progressive reveal effects
- `assets/images/favicon.svg` — brand favicon
- `robots.txt` — crawler instructions
- `sitemap.xml` — initial sitemap

## Development principles

- Black and white editorial visual identity with a restrained lime accent.
- Mobile-first responsive behaviour and accessible navigation.
- Lightweight HTML, CSS and vanilla JavaScript.
- No paid hosting or build step.
- No invented clients, endorsements, testimonials or performance claims.
- Demonstration concepts are clearly distinguished from commissioned work.
- Photography and commercial usage permissions must be agreed before publication.

## Publishing

The site is designed for GitHub Pages from the `main` branch, root folder. Enable or confirm this setting under **Settings → Pages** in the repository.
